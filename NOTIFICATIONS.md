# Native notification tab

The earlier build requested the automotive navigation variant, which does not guarantee a notification tab in the server response. Version 0.1.5 normalizes the native pivot model list before `pgu.O(afpw)` assigns it to the renderer and endpoint index.

- `phb.h(afpw)` returns immutable `arbh<antv>`; the insertion preserves all existing models and their endpoint/label/badge fields.
- A server notification model is reused and deduplicated. Otherwise the original `bbhx` and `bbic` builders create the missing model, with the original `TAB_ACTIVITY_CAIRO` icon and a localized label.
- Its `avfw` command carries the original `aupv.a` browse extension (`aupr`, browse ID `FEactivity`). Existing native routing, badge counters and account/session code handle the inbox.
- The notification model is inserted immediately after `FEsubscriptions`, before the account model. No added view or overlay is involved. Disabled Inhouse leaves the model list unchanged.
- Instrumentation uses the actual shipped protobuf builders, `antv` factory, immutable list, text renderer and native command decoder, and verifies ordering, original model identity, deduplication and disabled behavior. Logged-out emulator checks do not establish authenticated notification delivery.
